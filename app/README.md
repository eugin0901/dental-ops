# 치과 운영 관리 (여러 치과용) 설치·운영 안내

소규모 치과 여러 곳이 **하나의 사이트**에서 각자 가입해 쓰는 버전이에요. 치과끼리 데이터는 완전히 분리돼요.

- **운영자(나)**: 아래 설치를 **한 번만** 해요. 그다음부터는 `admin.html`에서 치과별 사용량과 의견을 봐요.
- **각 치과**: 사이트에 들어와 카카오로 로그인하고 '새 치과 등록'만 하면 바로 써요. 설치할 것이 없어요.

## 들어 있는 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 치과 직원들이 쓰는 사이트 |
| `admin.html` | 운영자 대시보드 (메뉴별 사용량, 치과별 현황, 의견) |
| `config.js` | Supabase 주소·키, 서비스 이름, 글자 인식 사용 여부 |
| `supabase/schema.sql` | 데이터베이스 설정 (한 번만 실행) |
| `supabase/functions/lab-ocr/index.ts` | 기공 의뢰서 글자 인식 (🔒 잠김, 지금은 배포 안 함) |
| `supabase/functions/notify/index.ts` | 휴대폰 알림 발송 (무료) |
| `manifest.webmanifest`, `sw.js`, `icons/` | 휴대폰 홈 화면 설치와 알림 받기 |
| `qr.js` | 재료함 QR 스티커 만들기 |

## 운영자 설치 (한 번만, 약 1시간)

### 1. Supabase 프로젝트 만들기
1. https://supabase.com 에 가입하고 **New project**를 누르세요. Region은 **Northeast Asia (Seoul)**로 고르세요.
2. 데이터베이스 비밀번호는 안전한 곳에 적어 두세요.

### 2. 데이터베이스 설정
1. **SQL Editor**에 `supabase/schema.sql` 내용을 전부 붙여넣고 **Run**을 누르세요.
2. 이 설정으로 치과 테이블, 치과별 보안 규칙, 사진·서류 저장소, 사용 통계, 의견 테이블이 한 번에 만들어져요.

### 3. config.js 채우기
- `SUPABASE_URL`: Project Settings → API의 **Project URL**
- `SUPABASE_ANON_KEY`: **anon public** 키 (화면에 따라 Publishable key)
- `SERVICE_NAME`: 로그인 화면에 보일 서비스 이름

> ⚠️ **service_role**(Secret) 키는 절대 넣지 마세요.

### 4. 사이트 올리기 (Netlify)
1. https://app.netlify.com/drop 에 이 폴더를 끌어다 놓으세요.
2. 사이트 주소(예: `https://dental-ops.netlify.app`)를 적어 두세요.
3. 운영자 화면 주소는 `https://사이트주소/admin.html`이에요.

### 5. 카카오 로그인 앱 만들기 (Kakao Developers)
1. https://developers.kakao.com → **애플리케이션 추가**를 누르세요. 앱 이름은 서비스 이름으로 하세요.
2. **카카오 로그인 활성화**를 ON으로 켜세요.
3. **Redirect URI**에 `https://<Supabase 프로젝트 주소>.supabase.co/auth/v1/callback`을 등록하세요.
4. **Client Secret**을 생성하고 **활성화**하세요.
5. **동의항목**에서 닉네임과 프로필 사진을 필수로 설정하세요. 이메일은 필요 없어요.
6. **REST API 키**와 **Client Secret**을 적어 두세요.

### 6. Supabase에 카카오 연결
1. **Authentication → Sign In / Providers → Kakao**에서 Enable을 켜세요.
2. Client ID에 REST API 키, Client Secret에 Client Secret을 넣으세요.
3. **Allow users without an email**을 켜세요.
4. **Authentication → URL Configuration**에서 **Site URL**과 **Redirect URLs**에 사이트 주소를 넣으세요. Redirect URLs는 끝에 `/**`를 붙여요.

### 7. 나를 운영자로 등록
1. `https://사이트주소/admin.html`에 들어가 카카오로 로그인하세요.
2. "운영자 권한이 없어요" 화면에 나오는 SQL 한 줄을 복사하세요.
3. Supabase **SQL Editor**에서 실행하고 새로고침하면 대시보드가 열려요.

### 8. 기공 의뢰서 글자 인식: 🔒 잠김, 지금은 건너뛰세요
**이 단계는 하지 마세요.** 기공물 메뉴는 "준비 중"이고, 글자 인식은 세 겹으로 잠겨 있어요. 그래서 실수로 따라 해도 Anthropic 요금이 나가지 않아요.
- 화면: `config.js`의 `COMING_SOON`에 `lab`이 있으면 `OCR_ENABLED`가 true여도 꺼져요.
- 서버: `lab-ocr` 함수는 Secrets에 `OCR_UNLOCK=yes`가 없으면 API를 부르지 않고 거절해요.
- 키: `ANTHROPIC_API_KEY`를 넣지 않으면 아무것도 청구되지 않아요.

나중에 기공물을 쓰기로 정했을 때만 아래 순서로 여세요. 사용한 만큼 Claude API 요금이 **운영자에게** 청구돼요.
<details><summary>나중에 열 때 순서 (지금은 펼치지 않아도 돼요)</summary>

1. https://console.anthropic.com 에서 API 키를 만들고, Limits에서 월 사용 한도를 정하세요.
2. Supabase **Edge Functions → Secrets**에 `ANTHROPIC_API_KEY`와 `OCR_UNLOCK` = `yes`를 추가하세요.
3. **Edge Functions → Deploy a new function → Via Editor**를 누르고, 이름을 `lab-ocr`로 정한 뒤 `supabase/functions/lab-ocr/index.ts` 내용을 붙여넣어 Deploy하세요.
4. `config.js`에서 `COMING_SOON`에서 `"lab"`을 빼고, `OCR_ENABLED: true`로 바꾼 뒤 Netlify에 다시 올리세요.
</details>

### 9. 휴대폰 알림 켜기 (무료, 약 15분)
단톡방 대신 휴대폰 알림으로 공지, 전체 알림, 업무, 장비 고장을 보내요. 알림 발송은 무료예요.
1. `https://사이트주소/admin.html` 맨 아래 **휴대폰 알림 키 만들기 → 키 만들기**를 누르세요. 공개 키와 비밀 키가 나와요. **한 번 만든 키는 계속 쓰세요.** 바꾸면 모든 직원이 알림을 다시 켜야 해요.
2. Supabase **Edge Functions → Secrets**에 4개를 추가하세요.
   - `VAPID_PUBLIC_KEY`: 공개 키
   - `VAPID_PRIVATE_KEY`: 비밀 키 (다른 곳에 붙여넣지 마세요)
   - `VAPID_SUBJECT`: `mailto:운영자이메일` (예: `mailto:ops@example.com`)
   - `CRON_SECRET`: 아무 긴 문자열 (예: 비밀번호 생성기로 만든 30자)
3. **Edge Functions → Deploy a new function → Via Editor**에서 이름을 `notify`로 정하고 `supabase/functions/notify/index.ts` 내용을 **전부** 붙여넣어 Deploy하세요. 파일 하나면 돼요.
4. `config.js`에서 `PUSH_ENABLED: true`, `VAPID_PUBLIC_KEY: "공개 키"`로 바꾸고 Netlify에 다시 올리세요.
5. (아침 알림) 매일 오전 8시 30분에 "내일 기한인 업무", "오늘 재료 주문일" 알림을 보내려면 **Database → Extensions**에서 `pg_cron`과 `pg_net`을 켠 뒤, SQL Editor에서 아래를 실행하세요. `프로젝트주소`, `anon키`, `CRON_SECRET값`을 바꿔 넣으세요.
```sql
select cron.schedule('dental-daily-push', '30 23 * * *',  -- 매일 한국시간 08:30 (UTC 23:30)
  $$ select net.http_post(
       url := 'https://프로젝트주소.supabase.co/functions/v1/notify',
       headers := jsonb_build_object('Content-Type','application/json',
                                     'Authorization','Bearer anon키',
                                     'x-cron-secret','CRON_SECRET값'),
       body := '{"daily":true}'::jsonb) $$);
```

6. (퇴근 알림) 관리자 설정의 "퇴근 알림 시각"에 맞춰 알림을 보내려면 아래도 실행하세요. 10분마다 확인해요.
```sql
select cron.schedule('dental-leave-push', '*/10 * * * *',
  $$ select net.http_post(
       url := 'https://프로젝트주소.supabase.co/functions/v1/notify',
       headers := jsonb_build_object('Content-Type','application/json',
                                     'Authorization','Bearer anon키',
                                     'x-cron-secret','CRON_SECRET값'),
       body := '{"daily":true,"leave":true}'::jsonb) $$);
```

**어떤 알림이 누구에게 가나요**

| 일어난 일 | 받는 사람 |
|---|---|
| 새 공지 | 그 치과 모든 직원 |
| 전체에게 짧게 알리기 | 그 치과 모든 직원 (화면 맨 위 배너 + 확인 버튼) |
| 업무 전달 | 받는 사람 |
| 업무 완료 | 보낸 사람 |
| 장비 고장 접수 / 수리 완료 | 그 치과 모든 직원 |
| 재고가 최소 수량 아래로 | 그 구역 재고 담당자 (없으면 관리자) |
| 근무표 변경 | 근무가 바뀐 직원 |
| 매일 아침 | 내일 기한인 업무가 있는 직원, 주문일의 재고 담당자 |

- 내가 한 일은 나에게 알리지 않아요. 같은 알림은 한 번만 가요.
- 알림 문구는 서버가 기록을 보고 만들어요. 앱에서 아무 문구나 보낼 수 없어요.
- 직원이 **내 화면 → 내 이름 고르기**를 해야 업무·근무표·재고 알림이 그 사람에게 가요.

### 10. 출퇴근 와이파이 (무료, 약 5분)
치과 와이파이에 연결된 휴대폰에서만 출퇴근이 찍히고, 앱을 열면 자동으로 출근이 찍혀요. 위치(GPS)는 쓰지 않아요.
1. **Edge Functions → Deploy a new function → Via Editor**에서 이름을 `punch`로 정하고 `supabase/functions/punch/index.ts` 내용을 붙여넣어 Deploy하세요. (따로 넣을 Secrets는 없어요)
2. 각 치과 관리자가 **치과 안에서 치과 와이파이에 연결한 채로** 더보기 → 관리자 설정 → **출퇴근 와이파이 → 지금 이 와이파이를 치과로 등록**을 눌러요.
3. "치과 와이파이에서만 출퇴근 찍기", "앱을 열면 자동으로 출근 찍기"를 켜고, 퇴근 알림 시각을 정해요.
- 퇴근은 자동으로 찍히지 않아요. 직원이 퇴근 버튼을 누르고, 안 누르면 퇴근 알림 시각에 휴대폰 알림이 가요.
- "와이파이에서만 찍기"를 켜면 직원은 출퇴근 기록을 직접 고칠 수 없어요. 관리자는 고칠 수 있어요.
- 치과 인터넷 주소가 바뀌면(가정용 회선 등) 관리자가 등록 버튼을 다시 누르면 돼요.
- 직원들에게 이렇게 기록한다는 걸 미리 알리고 동의를 받아 두세요.

## 치과가 시작하는 방법 (각 치과 10분)

1. **치과 관리자**(원장님이나 실장님)가 사이트에 들어가 **카카오로 로그인** → **새 치과 등록**을 해요. 등록한 사람이 그 치과의 관리자가 돼요.
2. 관리자 화면 맨 위의 **처음 설정 도우미 [시작하기]**를 눌러요. 진료 시간, 시작 단계, 직원, 예시 역할·매뉴얼을 5분 안에 한 번에 정해요. 미리 받은 **셋팅 질문지** 답을 보면서 넣으면 빨라요. 나중에 **관리자 설정 → 처음 설정 도우미 [다시 열기]**로 고칠 수 있어요.
3. **관리자 설정 → 직원 초대**에서 **초대 문구 복사**를 눌러 직원 단톡방에 보내요. 링크에 초대코드가 들어 있어서, 직원이 링크로 들어오면 코드가 자동으로 입력돼요.
4. 직원이 카카오로 로그인 → **합류 신청**을 해요.
5. 관리자가 **관리자 설정 → 직원 승인**에서 승인해요.
6. 새 치과는 **1단계 · 소통부터**(공지, 업무 전달, 근무표만)로 시작해요. 직원이 익숙해지면 **관리자 설정**에서 2단계(재고·기공물·소독·거래처), 3단계(장비·출퇴근·매뉴얼·마케팅까지 전체)로 올려요. 메뉴를 하나씩 직접 켜고 끌 수도 있어요. 기록은 지워지지 않아요.
6. 직원은 로그인하면 **내 화면**이 먼저 나와요. 처음 한 번 "○○○님이 맞나요?"에 답하면 오늘 근무, 나에게 온 업무, 안 읽은 공지, 남은 연차, 이번 주 근무만 모아서 보여 줘요. 연결은 카카오 계정 기준이라 휴대폰을 바꿔도 유지돼요.
7. **역할·할 일**: 관리자가 **역할·할 일** 메뉴에서 역할(예: 소독실, 오픈 준비, 마감)과 담당 직원, 그날 할 일을 정해요. **예시 역할 넣기**로 시작하면 편해요. 할 일 앞에 `[월]`, `[월,목]`을 붙이면 그 요일에만 나와요. 담당 직원의 내 화면에 오늘 체크리스트가 뜨고, 모두가 보는 전체 현황에는 역할마다 담당자와 **미완료 / 하는중 / 완료**가 보여요. 누가 몇 시에 바꿨는지 남고, 담당자가 휴무·연차면 표시돼서 다른 사람이 대신 할 수 있어요. 역할은 관리자만 고칠 수 있고, 체크는 모두 할 수 있어요.
8. **휴대폰 알림 켜기** (각 직원, 한 번만): 내 화면 맨 위 **알림 켜기**를 누르고 허용하세요. 시험 알림이 바로 와요. 받고 싶은 알림 종류는 같은 자리에서 고를 수 있어요.
   - **아이폰**: 사파리에서 **공유 → 홈 화면에 추가**를 먼저 하고, 홈 화면 아이콘으로 들어와서 알림을 켜야 해요 (iOS 16.4 이상).
   - **안드로이드**: 내 화면의 **홈 화면에 설치** 버튼을 누르면 앱처럼 아이콘이 생겨요.
9. **전체에게 짧게 알리기**: 내 화면이나 치과 현황에서 한 줄을 보내면 모든 직원 화면 맨 위에 배너가 뜨고 휴대폰 알림이 가요. 각자 **확인**을 누르면 보낸 사람이 "확인 3명: ○○, ○○…"를 볼 수 있어요. 단톡방의 "확인했습니다" 답장을 대신해요.
10. **재료함 QR 스티커**: 재료 관리 메뉴 → **QR 스티커 인쇄** → 분류와 크기를 고르고 인쇄해서 서랍·재료함에 붙여요. 재료를 꺼낼 때 휴대폰 기본 카메라로 찍으면 그 품목 화면이 열리고 **1개 사용 (−1)** 버튼 하나로 끝나요. 최소 수량 아래로 내려가면 재고 담당자에게 알림이 가고 주문 견적서에 자동으로 들어가요. 박스 단위 재료는 "새 박스 뜯을 때 한 번 찍기"로 정하면 편해요.
11. 쓰다가 불편한 점은 화면 오른쪽 아래 **의견 보내기**로 보내요. 운영자 대시보드에 바로 모여요.

## 운영자 대시보드로 보는 것
- **메뉴별 사용량**: 메뉴마다 연 횟수와 저장한 횟수, 쓰는 치과 수, 끈 치과 수를 보여 줘요. 치과별 히트맵으로 "필요 없는 메뉴" 후보를 찾을 수 있어요. **기록 내용은 수집하지 않고 횟수만 세요.**
- **치과별 현황**: 직원 수, 승인 대기, 기록 수, 최근 사용일, 7일 사용자 수를 보여 줘요. 한동안 안 쓴 치과는 연락해 보세요.
- **의견**: 상태를 '새 의견 → 검토 중 → 반영 예정 → 반영 완료'로 바꿔 관리해요. 바꾼 상태는 해당 치과 관리자 화면에도 보여요.
- CSV로 내려받아 엑셀에서 분석할 수 있어요.

## 보안 구조 (확인 완료)
- 치과끼리 기록, 사진, 서류, 의견을 볼 수 없어요. 데이터베이스 보안 규칙으로 막혀 있어요.
- 합류 신청자는 승인 전까지 아무것도 볼 수 없고, 스스로 승인하거나 소속 치과를 바꿀 수 없어요.
- 직원의 관리자 전용 정보와 첨부 서류는 그 치과 관리자만 볼 수 있어요.
- 공지, 업무 전달, 전체 알림은 작성자만 삭제할 수 있어요.
- 휴대폰 알림 구독 정보는 본인만 등록·삭제할 수 있고, 알림을 받을 사람과 문구는 서버가 정해요. 다른 치과 직원에게는 알림을 보낼 수 없어요.
- **운영자도 치과의 기록 내용은 볼 수 없어요.** 볼 수 있는 건 사용 횟수와 의견뿐이에요.

## 파일럿 전에 꼭 챙길 것
- **개인정보**: 여러 치과의 직원 정보(연락처, 근태, 서류 등)가 운영자의 Supabase에 저장돼요. 파일럿이라도 **개인정보 처리방침**을 만들고 각 치과와 **이용 약관 또는 처리 위탁 동의**를 받아 두세요. 법률 검토를 권해요.
- **환자 정보 금지**: 기록 칸에는 환자 실명·연락처·진료 내용을 넣지 않도록 안내하세요. 의뢰서 사진은 장착 후 정리하세요.
- **용량과 백업**: Supabase 무료 플랜은 용량 한도가 있고 자동 백업이 없어요. 참여 치과가 늘면 유료 플랜을 검토하고, 매달 **Table Editor → Export**로 백업하세요.
- **일시 정지**: 무료 플랜은 일주일 동안 사용이 없으면 일시 정지돼요. 치과들이 매일 쓰면 문제없어요.

## 매뉴얼 PDF·사진 (2026-11 추가)
- `supabase/schema.sql`을 SQL Editor에서 **한 번 더 실행**하면 `manual-files` 저장소가 만들어져요. (이미 있는 데이터는 그대로예요)
- `vendor/pdfjs/` 폴더(PDF를 이미지로 바꾸는 pdf.js, Apache-2.0)를 사이트와 **같이 올려야** 해요. Netlify에 폴더째 올리면 돼요.
- PDF는 올릴 때 휴대폰·PC에서 쪽마다 이미지로 바뀌어 저장되고, 원본 PDF도 함께 남아요. 파일당 20MB, 매뉴얼당 60장까지예요.

## 수정 배포
`index.html` 등을 고친 뒤 Netlify **Deploys**에 폴더를 다시 끌어다 놓으면 모든 치과에 한 번에 반영돼요. 데이터는 그대로예요.
